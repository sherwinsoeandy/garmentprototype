# Garment Inventory - Basic Starter Project

A simple browser-based inventory starter project built with plain HTML, CSS, and JavaScript.

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the **Live Server** extension (Ritwick Dey).
3. Right-click `index.html` and select **Open with Live Server**.

## Languages
- English (default)
- Traditional Chinese (繁體中文)
- Tagalog

Use the **Language** selector in the top-right area. Your language preference is saved in this browser.

## Included features
- Dashboard
- Item catalog (raw materials and finished products)
- Stock-in transactions
- Flexible batch conversion (multiple materials and multiple products)
- Sales / stock-out transactions
- Transaction history and detail view
- JSON backup export

## Data storage
Inventory data is stored in this browser using `localStorage`. It is not shared with other computers or browsers. Export a JSON backup regularly. This starter project does not yet include a server database, authentication, or multi-user synchronization.
